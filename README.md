# 🌍 Акватуриум

Симуляция эволюции цифровой экосистемы прямо в браузере.

Проект моделирует жизнь примитивных существ, их развитие, взаимодействие, борьбу за ресурсы и формирование социальных структур — от одиночек до мегаструктур.

---

## ⚙️ Возможности

* 🧬 Эволюция существ (рост, мутации, размножение)
* 🧠 Поведение с примитивным правилами

  * охота
  * избегание угроз
  * поиск колоний
* 🏛 Социальные структуры:

  * одиночки
  * колонии
  * империи
  * мегаструктуры
* ⚔️ Боевая система и поглощение
* 🌱 Экосистема:

  * почва
  * трупы → переработка в ресурсы
  * территориальное влияние
* 🌊 Катаклизмы:

  * метеорит
  * засуха
  * генетический шторм
  * потоп
* 🌙 Цикл дня и ночи
* 📜 Лог событий (летопись мира)

---

## 🎮 Управление

| Кнопка     | Действие              |
| ---------- | --------------------- |
| ⏸ Пауза    | остановка симуляции   |
| ⚡ x5       | ускорение времени     |
| ☄ Метеорит | локальное уничтожение |
| ☀ Засуха   | отключает фотосинтез  |
| 🧬 Шторм   | увеличивает мутации   |
| 🌊 Потоп   | глобальная катастрофа |

Дополнительно:

* клик по существу → информация
* клик по "Колонии / Империи / Мегаструктуры" → подсветка

---

## 🚀 Запуск

Просто открой файл в браузере:

```bash
open world.html
```

или двойной клик — и поехали.

Никаких зависимостей, чистый HTML + Canvas.

## 🧱 Технологии

* HTML5
* Canvas API
* Vanilla JavaScript

---

## 🧪 Как это работает

* Каждое существо — набор сегментов (по сути “червь”)
* Имеет:

  * энергию
  * вес
  * возраст
* Поведение зависит от:

  * окружающих существ
  * социальной структуры
  * среды

### Ключевые механики:

* **Фотосинтез** (днём)
* **Метаболизм** (энергозатраты)
* **Хищничество**
* **Размножение с мутациями**
* **Формирование колоний → империй → мегаструктур**
